How Sherlock's first brain works

A deliberately small, understandable starting point.

1. LearnCount words
2. CompareEstimate categories
3. PredictChoose best match

This prototype uses a simple Multinomial Naive Bayes classifier. It counts how often words appear in each category, then estimates which category best fits a new sentence. It does not understand language like ChatGPT does. The goal is to give us a small model we can inspect, train, and improve.
