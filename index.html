Adaptive batches aim for about 30 ms per C++ call, adjusting between 16,384 and 196,608 characters. This balances throughput with interface responsiveness. The engine is still single-threaded, so this upgrade does not yet use all four CPU cores. Browsers do not expose reliable system-wide iPad CPU-use percentages to webpages.
