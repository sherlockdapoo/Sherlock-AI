02 · Inside the neural network

The full path from a short character context to a prediction.

10,160 PARAMETERS
Input contextPrevious 4 characters · 128-character alphabet
Learned embeddings12 trainable numbers per character · 48 input values
Hidden layer48 neurons · ReLU activation
Output layer128 character scores · softmax probabilities
Learning algorithmCross-entropy loss · backpropagation · Adam
This is a small character-level multilayer perceptron (MLP), not a transformer yet. Its weights are updated from prediction errors. The earlier C++ counter is kept as an archived baseline. Chat uses this network after its first training run.
